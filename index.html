Two ways to hoop

Play Now

Full-court 5v5 in a packed arena. Quarters, a game clock, a 24-second shot clock, overtime, fouls and a full box score at the final buzzer.

Blacktop

Half-court 3v3, 2v2 or 1v1 street ball on an outdoor court. 1s and 2s, first to 11 (win by two), a 12-second shot clock, and you have to clear it after a stop.

Skill shooting

Hold and release at the top of the meter. The green window shrinks as a defender closes out, and a perfect release on an open look always drops.

Real handles

Crossovers, behind-the-backs, spins, hesis and step-backs. Start a move with the ball in your hand for a sharper burst; chain too many and you'll cough it up.

How to install

  1. Click Download for Windows (it opens in a new tab) and grab the .zip under Assets.
  2. Right-click the zip → Extract All.
  3. Open the folder and run Courtside.exe. If Windows SmartScreen appears, choose More info → Run anyway (the game isn't code-signed yet).
  4. The first launch prepares shaders for a minute; after that it starts quickly.

On a school computer? If the download is blocked, download the zip at home and bring it on a USB drive. You don't need admin rights to run it.
